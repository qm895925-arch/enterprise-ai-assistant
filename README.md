# Enterprise AI Assistant

An enterprise AI knowledge assistant built with Python, FastAPI, RAG and LLM technologies.

## Project Overview

Enterprise AI Assistant is an AI-powered knowledge assistant designed to help users interact with enterprise knowledge through natural language.

The project will gradually evolve from a simple FastAPI application into a production-oriented AI system with:

- Document upload and management
- RAG-based knowledge retrieval
- Vector database integration
- LLM-powered question answering
- Multi-turn conversations
- AI Agent workflows
- Streaming responses
- Docker deployment

## Tech Stack

### Backend

### AI Stack

- LLM

### Infrastructure

- PostgreSQL
- Qdrant
- Docker
